# Block serialization baseline fixtures

Captured from the unmodified `BlockTransformer` at Qortal commit
`108bf191d42d710ec617f535af30cfd82fc03c87` using the deterministic inputs in
`BlockSerializationTests.createBlock`, before changing the serializer.
These files are the complete serialized bytes, not hashes generated by the
new implementation. V1 cases guard the existing public length API; V2 cases
cover cached/uncached states, zero/one/many states, skipped initial states,
payment and excluded AT transactions, and online account signatures/nonces.
No database, node, wallet or network is used by the fixture test.

The cached cases intentionally preserve the existing SHA-256 of the supplied
cached hash. Do not change this behavior as part of an allocation optimization.
